# Dmart Grocery Redesign

This folder contains the website improvement project in separate files.

Files:
- `shop.html` - selected product listing page with the functional search improvement
- `product-bananas.html` - product page for bananas
- `product-cucumbers.html` - product page for cucumbers
- `product-carrots.html` - product page for carrots
- `product-brocolli.html` - product page for brocolli
- `cart.html` - cart page with instant quantity updates, address fields, and add more items button
- `checkout.html` - checkout page with the unified payment and billing section
- `styles.css` - shared styling
- `script.js` - shared JavaScript
- `assets/` - original logo and product images downloaded from the live Dmart website

Project note:
- The instructions said to keep 10 products, but the provided list named 9 products. This build follows the exact named list: Banana Peppers Yellow, Bananas, Blackberries, Blueberries, Carrots, Cauliflower, Cucumbers, Brocolli, and Cilantro.

Original website references:
- Original brand text, product names, prices, and downloaded images came from `https://dmartcs.com`
- Comments in the HTML, CSS, and JavaScript mark reused website content and improved sections
